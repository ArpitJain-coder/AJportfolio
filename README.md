## ✨ Features

- 🎨 **Silk WebGL Hero Shader**: Interactive 3D silk fluid shader backdrop powered by Three.js & `@react-three/fiber`.
- 🧭 **GSAP Magnetic Navigation**: Liquid hover animation header with active scroll section auto-highlighting.
- 📱 **Awwwards Fullscreen Mobile Menu**: Immersive mobile navigation overlay with staggered GSAP entrance timelines, numbered editorial layout, and scroll lock.
- ⚡ **Ultra-Responsive**: Fully optimized for mobile, tablet, laptop, desktop, and 4K displays.
- 📄 **Interactive Resume Page**: Integrated route (`/resume`) with dark/light sheet toggles and print-to-PDF support.
- 🚀 **Live Deployed Projects**: Direct links to production Vercel web applications.

## 💻 Local Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `yarn`

### Installation & Launch

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ArpitJain-14/AJportfolio.git
   cd AJportfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173`.

4. **Build for production**:
   ```bash
   npm run build
   ```
